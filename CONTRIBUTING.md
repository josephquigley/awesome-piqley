# Contributing to Awesome Piqley

Thank you for your interest in contributing!

## Adding a Plugin

To add your plugin to the list, open a pull request with the following:

1. Add your plugin under the **Plugins** section in `README.md`.
2. Use the format: `- [plugin-name](link) - Short description. (Platforms: macOS, Linux x86, Linux ARM)`
3. Keep the description concise (one sentence).
4. Place your entry in alphabetical order within its category.

## Guidelines

- The plugin must be published and publicly available.
- The plugin must work with a current release of piqley.
- Descriptions should start with a capital letter and end with a period.
- Include supported platforms in parentheses after the description: macOS, Linux x86, Linux ARM. List only the platforms the plugin has been tested on.
- One plugin per pull request makes review easier.

## Adding a Resource

Resources such as tutorials, blog posts, or tools that complement piqley are also welcome. Follow the same PR process and place the entry under **Resources**.
